# Textual Awakening

A filet crochet text pattern generator.

Live site: https://christinefeng.github.io/textual-awakening/

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
npm run lint
```

## Deploying

```bash
npm run deploy
```

This builds the site and publishes `dist/` to the `gh-pages` branch, which GitHub Pages serves. It deploys whatever is checked out locally, so deploy from an up-to-date `main`.
